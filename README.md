📊 Sales Performance Dashboard

An interactive Power BI dashboard for analyzing sales performance, profitability, customer behavior, and regional trends — built on Superstore sales data to give management a clear, actionable view of the business.

Power BI · Power Query · DAX · Excel

🎯 Project Overview

This project analyzes Superstore sales data to give management an interactive view of revenue, profitability, product performance, customer segments, shipping methods, and regional performance — enabling faster, data-driven decisions.

📊 Dashboard Features
Revenue & profit KPIs
Monthly sales and profit trends
Regional & state-level analysis
Category & subcategory performance
Customer segment analysis
Payment & shipping mode analysis
Interactive regional filtering
Sales forecasting
